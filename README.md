# 🍕 Pizza Sales Analysis Dashboard

## 📊 Project Overview

This project is an interactive Excel Dashboard created to analyze pizza sales data and understand sales performance, customer preferences, and business trends.

The dashboard provides useful insights into pizza sales through interactive charts, tables, and visualizations.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## 📈 Dashboard Analysis

The dashboard analyzes:

- Total Revenue
- Total Orders
- Total Pizzas Sold
- Average Order Value
- Average Pizzas per Order
- Daily and monthly sales trends
- Sales by pizza category
- Sales by pizza size
- Top-selling pizzas
- Bottom-selling pizzas

## 🔍 Key Insights

The dashboard helps identify:

- Which pizza categories generate the highest sales
- Which pizza sizes are most popular
- The best-selling pizza products
- Sales trends across different days and months
- Overall pizza sales performance

## 📁 Project File

- `Pizza Sales Dashboard.xlsx` – Interactive Excel dashboard

## 🎯 Project Objective

The objective of this project is to use Excel to transform pizza sales data into meaningful business insights that can help understand customer preferences and improve sales performance.
